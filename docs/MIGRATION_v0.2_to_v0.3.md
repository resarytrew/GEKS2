# Миграция v0.2 → v0.3

`restoreSaveGame` принимает неизвестное значение, проверяет envelope,
мигрирует поддерживаемые старые поля и затем воспроизводит команды от
нового начального состояния.

## Изменения схемы

- `schemaVersion` повышен до 3.
- Добавлены `engineVersion`, `scenarioVersion`, `stateVersion`.
- Добавлены `matchId`, `mode`, фиксированный `seed`.
- Введены `plans`, `impulse`, `contacts`, `supplySources`.
- Добавлены `processedCommandIds` и `scoredEventIds`.
- Зоны карт нормализованы до `deck/hand/committed/resolved/discard/removed`.
- HQ представлены также в `units` и стеке гекса.
- Старые фазы преобразуются в начало нового WEGO-цикла; точный прогресс
  незавершённой legacy-активации не переносится.

## Безопасное поведение

Отсутствующие необязательные поля получают детерминированные значения.
Неизвестный scenario id, будущая версия схемы, некорректный seed или
повреждённый журнал возвращают ошибку. Миграция не доверяет готовому
client-side результату: authoritative state строится replay команд.

Перед обновлением рекомендуется сохранить исходный JSON отдельно. Партия,
которая зависела от точного промежуточного состояния старой последовательной
активации, может быть продолжена только в `legacy_debug` или начата заново.
