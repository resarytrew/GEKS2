# Реестр исторических источников

Каноническая машиночитаемая версия находится в
`src/scenarios/baltic-1941/sources.ts`. Дата проверки ссылок:
2026-07-29.

| ID | Тип | Уверенность | Назначение |
|---|---|---|---|
| `ag-north` | открытый OOB | probable | Общая структура группы армий «Север» |
| `nwf` | первичный оперативный документ | reconstructed | Контекст действий 3-го и 12-го МК; не полный OOB 22 июня |
| `raseniai` | академическое исследование | reconstructed | Наличие и общий контекст боёв 23–25 июня |
| `kv` | академическое исследование историографии | disputed | Наличие КВ; детали одиночного эпизода спорны |
| `dir3` | первичный документ | confirmed | Существование и наступательная направленность директивы № 3 |
| `geo` | современные геоданные | placeholder | Опорное положение городов, не сеть 1941 года |

## Редакционные пределы

Реестр не подтверждает точные стартовые координаты, параметры дивизий,
состояние каждого моста или дорог, тайминг по импульсам и игровые эффекты
карт. Для них сохраняется метка `reconstructed` или `placeholder`.
