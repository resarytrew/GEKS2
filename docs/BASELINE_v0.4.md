## Фактически незавершённые части WEGO

- `executeImpulse()` обрабатывает только следующий шаг маршрута. Отдельных
  исполнителей для десяти типов приказов нет.
- Приказ без маршрута автоматически становится `completed`, поэтому
  `prepared_attack`, `defend`, `delay`, `reserve`, `recover`,
  `prepare_demolition` и `build_pontoon` не имеют фактического эффекта.
- Любая часть проходит ровно один гекс за импульс независимо от стоимости
  местности, дороги, погоды и класса движения.
- WEGO-перемещение создаёт `UNIT_MOVED` с `fuelSpent: 0` и не расходует топливо.
- Встречный контакт создаётся с `resolved: false`, после чего оба приказа
  ошибочно помечаются завершёнными. Resolver контактов отсутствует.
- Боевая модель используется только legacy-командой атаки и не включена в
  WEGO execution.
- Prepared attack не создаёт `CombatDeclaration`.
- Нет распределения потерь между всеми участниками WEGO-боя, разрешения
  многошагового отхода и автоматического продвижения в WEGO.
- Из реакций фактически работает только подрыв заранее подготовленного моста.
- Резерв, отход от окружения и прекращение атаки по порогу потерь не работают.
- Инженерные приказы не требуют времени исполнения.
- HQ отмечается как перемещённый, но движение штаба не создаёт полный набор
  последствий для сети командования.
- После шести импульсов происходит переход в общую `reaction`, а не
  автоматическое разрешение боёв и формирование After Action Report.
- `sanitizeStateForSide()` удаляет реакции и фильтрует приказы, но раскрытый
  контакт может показать будущий полный маршрут, карты и состав поддержки.
- UI создаёт только `march` с фиксированными параметрами.
- Нет `DailyAfterActionReport`, fixture `Raseiniai WEGO Test`,
  `validateStateInvariants()` и CI workflow.

## Расхождения README и кода

- README описывает встречные контакты как часть исполнения, но они только
  создаются и никогда не получают боевого результата.
- README говорит об импульсном исполнении приказов в целом, тогда как реально
  исполняются только маршруты `march/advance/withdraw`, и то одной клеткой.
- Заявленная транзакционность карт не означает их привязку к моменту исполнения
  приказа: `cardIds` в WEGO не применяются как отложенные эффекты.
- Описанный полный цикл до снабжения и конца суток отсутствует в основном
  WEGO-пути.
