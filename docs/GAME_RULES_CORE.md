# Правила ядра

В v0.4.1 только валидированный шаг движения может создать контакт. Участники,
поддержка и резерв разделены по атакующей и обороняющейся сторонам. Резерв после
ввода становится участником, но не поддержкой одновременно.

v0.4 uses fractional impulse movement, fuel and ammunition expenditure,
multi-hex retreats, defensive posture, reserves, engineer work and one canonical
CRT shared by legacy debug and WEGO combat.

## Масштаб и ход

Один гекс представляет приблизительно 10–13 км, одна основная фишка —
дивизию. Сутки состоят из планирования Германии, планирования СССР,
фиксации планов, исполнения импульсов, снабжения и завершения суток.

## Приказы и командные очки

Марш, атака, инженерные действия и карты имеют явную стоимость CP.
Команда сначала полностью валидируется. Недостаток CP, неверная стоимость
или повторное списание возвращают код ошибки и не меняют ни CP, ни карту.
Командование ищется только по штатной цепочке: корпусной штаб, допустимое
временное подчинение, затем родительская армия. Ближайший посторонний штаб
не используется.

## Движение и встречные контакты

Маршрут проверяется по соседству гексов, стоимости местности, мостам,
стэкингу и состоянию части. В каждом импульсе обе стороны делают следующий
допустимый шаг. Попытка войти навстречу противнику создаёт `Contact`; она
не разрешается скрытым последовательным преимуществом первой стороны.

## Бой

Preview и resolution используют один `CombatModel`: силы, местность,
снабжение, организацию, поддержку и свойства частей. Тяжёлая броня
применяется один раз. Уничтожение/отход защитника само по себе не меняет
контроль: атакующая сторона должна выбрать допустимую часть для
продвижения. Без продвижения гекс остаётся contested.

## Мосты

Состояние моста хранится на общем ребре. Подготовка к подрыву требует
допустимую инженерную часть; реакция подрыва возможна при подходе врага.
Строительство понтона или ремонт также требуют инженерной возможности и
ресурсов. Изменение видно с обеих сторон ребра.

## Снабжение и окружение

Маршрут снабжения строится от объявленного источника через проходимые
гексы и исправные переправы с учётом вражеской ZOC. Для полного снабжения
нужна связь с подходящим HQ. Состояния `full`, `limited`, `low`,
`isolated`, `none`, а также частичное/полное окружение выводятся из
реального маршрута, а не из числа соседних врагов.

## Карты

Карты проходят зоны `deck → hand → committed → resolved/discard/removed`.
Стоимость списывается транзакционно. Карта не является историческим
доказательством: её документальная основа и игровой эффект описаны
отдельно в реестре источников.

## Очки

Захват, удержание, потери и сохранение соединений считаются один раз.
Исторические сроки используют кривую: более раннее достижение может дать
бонус, опоздание уменьшает награду до установленного минимума. Финальные
цели сохранения проверяются при завершении сценария.
